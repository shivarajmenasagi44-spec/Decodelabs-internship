# Password Strength Checker

## Description

A Python-based Password Strength Checker developed as part of my Cybersecurity Internship at DecodeLabs.

The program checks password length, numbers, uppercase letters, symbols, and Unicode characters to classify a password as Weak, Medium, or Strong.

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

python project1.py

5. Enter your password when prompted.

## Technologies Used

- Python
- String Handling
- Conditional Statements
- any() function
- Unicode Character Handling
